## 应用架构

### 构建框架

该 APK 使用 **PakePlus** 框架构建。PakePlus 是一个将 Web 应用打包为 Android APK 的工具（类似于 PWA 封装工具），核心原理是使用 Android WebView 加载本地 HTML 资源。

### 技术栈

- **Android 层**: Kotlin + AndroidX + Material Design
- **Web 前端**: 原生 HTML/CSS/JavaScript（纯前端单页应用）
- **数据存储**: localStorage（浏览器本地存储）
- **依赖版本**:
  - Kotlin 协程: 1.6.4
  - AndroidX Core: 1.10.1
  - AndroidX AppCompat: 1.6.1
  - Material Design: 1.10.0
  - Navigation Component: 2.6.0
  - Fragment: 1.6.0
  - Activity: 1.8.0

## 应用功能：考勤管理系统

该应用是一个面向执法队伍的**考勤管理工具**，主要功能包括：

### 1. 加班申请 (`加班` 标签页)
- 选择加班日期
- 选择时间段（上午/下午/晚上/自定义）
- 选择加班原因（周六加班/周末加班/创城加班/自定义）
- 数据持久化保存到 localStorage

### 2. 补休申请 (`补休` 标签页)
- 选择补休日期
- 选择考勤队伍（执法一至四中队）
- 选择考勤组（蕉南一至四组）
- 选择班次（A7-A74 共 39 种班次）
- 锁定控制功能（可锁定队伍/组/班次选择，防止误操作）
- 关联已有的加班记录
- 自动恢复加班状态（删除补休时恢复加班为未使用）

### 3. 请假申请 (`请假` 标签页)
- 选择请假日期
- 选择时间段（上午/下午/自定义）
- 选择请假原因（事假/病假/自定义）

### 4. 历史视图 (`历史` 标签页)
- 统计总览（加班总次数、补休总次数、剩余次数）
- 过期提醒（加班记录超过 30 天未使用）
- **万年历**（按月份导航，标记加班/补休/请假事件）
- 事件详情弹窗（查看和删除记录）

### 5. 数据导出 (`导出` 标签页)
- 按年份/月份筛选
- 按类型筛选（加班/补休/请假/全部）
- 可自定义导出字段
- 支持模板选择（基础/详细/全选/清空）
- CSV 格式导出下载

## 安全分析

### 发现的配置
- `android.permission.INTERNET` - 网络权限（基础 WebView 需要）
- `android.permission.DUMP` - 诊断信息权限
- `allowBackup` - 允许备份
- `compileSdkVersion` - 在 manifest 中可识别

### 自定义 JS (custom.js)
- 集成了 Google Analytics (G-W5GKHM0893)
- 劫持了 `window.open` 和链接点击事件，强制在 WebView 内打开链接
- 实现了 `hookClick` 事件捕获，处理 `target="_blank"` 链接

### 潜在问题
- 使用 `localStorage` 存储考勤数据（数据在清除浏览器缓存后会丢失）
- 无后端服务，数据仅存储在本地设备
- 无用户身份验证机制

## 总结

这是一个使用 **PakePlus** 工具将 Web 应用（考勤管理系统）打包为 Android APK 的项目。应用本身是一个纯前端的单页 HTML 应用，通过 Android WebView 渲染。数据存储在浏览器的 `localStorage` 中。

应用面向执法队伍管理人员，提供加班、补休、请假的记录管理和数据导出功能，包含完整的万年历视图、统计概览和过期提醒机制。

该 APK 无后端服务、无用户认证系统，所有数据仅存储在本地设备中。
